# Credits and free tools

The kit points to these free, open-source projects. None of their code is
bundled here: install them from their own repos, under their own licenses.

| Tool | What it's for | Link |
|---|---|---|
| ccusage | Summarize Claude Code usage from local logs (`npx ccusage`) | https://github.com/ccusage/ccusage |
| claude-code-router | Route Claude Code requests to different models or providers per task | https://github.com/musistudio/claude-code-router |
| Graphify | Knowledge graph of your codebase for Claude Code and Codex (PyPI package `graphifyy`) | https://pypi.org/project/graphifyy/ |
| Context7 | Current library docs in context, so fewer retries on outdated APIs | https://github.com/upstash/context7 |
| markitdown | Convert PDFs and Office files to Markdown locally | https://github.com/microsoft/markitdown |

`claude-code/hooks/filter-test-output.sh` is adapted from the example hook in
Anthropic's "Manage costs effectively" documentation.
