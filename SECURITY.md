# Security policy

The hooks in this kit run on your machine whenever Claude Code calls the Read or Bash tool, so we treat any way to make them run unexpected commands or leak data as a security issue.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/brianweerasinghe/token-saver-kit/security/advisories/new), or email contact@aieatingtheworld.com with the details and steps to reproduce.

We aim to reply within 5 business days and to publish a fix, with credit if you want it, once it's ready.

## Supported versions

Only the latest release on `main` gets fixes.
